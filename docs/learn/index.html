Protocol Concepts & Trust Model

Understand how Ordex achieves trustless Bitcoin peer-to-peer trading without multi-sig escrows, smart contracts, or bridge custody.

1. Portable Public Asks

Sellers sign an input with SIGHASH_SINGLE | ANYONECANPAY, cryptographically locking their ordinal input to a specific payment output index. The ask is portable and verifiable by any gateway or marketplace.

2. Buyer-Funded Offers

Buyers commit funds into a Taproot script-tree output. If the seller delivers before the timelock, the seller takes payment; otherwise, the buyer exercises the unilateral recovery script path.

3. Sat-Flow Invariant

Ordinal inscriptions travel with specific satoshis across transaction inputs and outputs. Ordex verifiers check sat ranges to ensure assets are never diluted, burned, or sent to miner fees.
