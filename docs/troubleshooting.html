Follow the evidence, one signal at a time.

Most surprises become clearer when you check the order identity, its latest state, and the Ordex experience currently showing it.

The order is pending

Pending means there is not enough current evidence to call the order verified. Wait a moment and refresh. If it stays pending, use a different trusted Ordex experience or ask the publisher to share a fresh order. Do not treat pending as live.

The order is unavailable or rejected

An unavailable order may reference an input that has already moved or an asset condition that no longer matches. A rejected order did not pass structural or safety review. In either case, stop. Do not edit the artifact or bypass the warning; request a newly created order from its publisher.

Verification is not reservation.

A successful check observes a moment in time. Another Bitcoin transaction can still spend the same public input later.

The order was withdrawn

Withdrawal removes the order from one inventory view. It does not spend Bitcoin, erase copies from other places, revoke a signed event everywhere, or reverse a transaction. Refresh the evidence before assuming anything about its current status.

The order appears in one place but not another

Compatible markets may see different relay history, apply different display choices, or refresh at different times. Compare the order identity and publisher signature first. If they match, the visibility difference does not necessarily mean the underlying evidence changed.

A signing request did not complete

  • Make sure your NIP-07 signer is unlocked and allowed for the page you trust.
  • Read the approval request and confirm it describes the evidence you intend to share.
  • If you approved but cannot find the order, wait briefly and refresh before signing again.
  • Never paste a Nostr private key, wallet seed phrase, or Bitcoin signing secret into Ordex.

Safe next steps

  • Record the order identity, publisher, and state shown on screen.
  • Refresh the order immediately before any wallet action.
  • Stop if an asset, input, destination, amount, or fee is unexpected.
  • Use a wallet you trust for settlement and review every detail there.
  • Remember that confirmed Bitcoin transactions are difficult to reverse.
