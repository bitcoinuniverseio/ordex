Follow the evidence, one signal at a time.

Most surprises become clearer when you check the order identity, its latest state, and the Ordex experience currently showing it.

The listing says it is being checked

That means Ordex has not been able to reach its Bitcoin node or its inscription index for this listing yet. Wait a moment and refresh. If it stays that way, the market itself will say that checks are unavailable and why; nothing can be bought or created until they come back. Do not treat a listing being checked as one that is for sale.

The listing is being spent, gone, or not usable

Being spent means an unconfirmed transaction is already spending the output the listing sells; it may still be replaced or dropped, so nothing is settled. No longer available means that spend confirmed in a block, and the listing cannot be bought. Sold means the transaction Ordex checked for this listing is the one that spent the output. Not usable means the artifact or its safety profile did not pass review. In every one of these cases, stop. Do not edit the artifact or bypass the warning; ask the seller for a newly created listing.

Verification is not reservation.

A successful check observes a moment in time. Another Bitcoin transaction can still spend the same public input later.

The listing was removed

Removing a listing takes it out of one market. It does not spend Bitcoin, erase copies elsewhere, revoke a signed event everywhere, or reverse a transaction: anyone already holding the signed order can still complete it. Spend the output from your own wallet if you need a public order to stop working for certain.

Only the key that owns the output a listing sells can remove it. Ordex asks your wallet to sign a short challenge naming that listing, so nobody else can take your listing down and you never hand an operator credential to a web page.

The order appears in one place but not another

What you browse comes from the gateway a market is connected to, not from relays, so two markets connected to different gateways can hold different inventory and refresh at different times. Compare the order identity and publisher signature first. If they match, the visibility difference does not necessarily mean the underlying evidence changed.

A signing request did not complete

  • Make sure your NIP-07 signer is unlocked and allowed for the page you trust.
  • Read the approval request and confirm it describes the evidence you intend to share.
  • If you approved but cannot find the order, wait briefly and refresh before signing again. Announcing the same listing twice is safe: a relay keys on the event, so a retry never creates a duplicate.
  • Never paste a Nostr private key, wallet seed phrase, or Bitcoin signing secret into Ordex.

Safe next steps

  • Record the order identity, publisher, and state shown on screen.
  • Refresh the order immediately before any wallet action.
  • Stop if an asset, input, destination, amount, or fee is unexpected.
  • Use a wallet you trust for settlement and review every detail there.
  • Remember that confirmed Bitcoin transactions are difficult to reverse.
