Market integration

Make your market inventory portable without giving up verification.

Integrate the Ordex API as a discovery and review layer. Your UI can use the market-operated gateway by default while allowing advanced users to select a self-hosted gateway.

Connection modes

Default

Market gateway

Keep the Ordex gateway field empty. The client uses the marketplace's current API origin or configured Ordex URL.

Independent

User gateway

Users enter a credential-free URL to an Ordex gateway they operate. Store only that URL locally in the browser.

Never direct

Core credentials

The browser must never call Core RPC or ord with credentials. That belongs inside the chosen gateway.

Inventory API

EndpointUse
GET /api/ordex/catalogProtocol templates and settlement capability

POST /api/ordex/orders/importIndex a user-provided PSBT artifact
POST /api/ordex/orders/openordex-eventVerify and index a signed kind-802 event
GET /api/ordex/orders/:id/nostr-envelopePrepare the unsigned event that a NIP-07 signer will sign

Raw PSBT artifacts are excluded from the standard inventory response. They are requested only through the explicit artifact-review route.

Live Nostr publish

  1. A user creates or attaches a reviewed PSBT order.
  2. The client requests its Nostr envelope from the active Ordex gateway.
  3. The user's NIP-07 extension signs the event after a visible prompt.
  4. The browser sends the signed event to relay URLs the user configured.
  5. The client posts the same signed event to the active gateway, which verifies the event id and Schnorr signature before indexing it.

Relay acknowledgement matters.

Publish success means at least one configured relay returned an OK acknowledgement. A signing prompt alone is not delivery.

UI contract

Show protocol/token/source filters and the verification state close to every listing. Distinguish public/raceable asks from targeted review profiles. “Withdraw” must say it removes local inventory only; it cannot spend the source UTXO or retract every copy of a public event.

Use the connection panel to explain the two gateway modes and relay configuration. It should never contain wallet seed phrases, Core RPC credentials, or Nostr private-key fields.

Settlement limits

Bitcoin-family templates accept a user-created PSBT handoff. Dogecoin and Counterparty/Stamps templates are external settlement intents until a matching chain-specific verifier is deployed. Ordex does not combine, sign, fund, or broadcast PSBTs.
