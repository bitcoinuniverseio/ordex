Architecture

One orderbook. Many independent sources of truth.

Ordex moves market evidence between participants without asking markets to share custody, private node credentials, or a single central database.

Design principle

Ordex separates the four concerns that centralized marketplaces tend to collapse: submitting an order, verifying its chain state, distributing discovery data, and settling a trade. Each concern has an explicit owner and an observable record.

01

Artifacts are portable

PSBT evidence is not locked inside the database of the market that first observed it.

02

Verification is local

A gateway checks the chain and indexer it is configured to trust, then reports a time-bound result.

03

Distribution is signed

A publisher uses their own Nostr signer to make a discovery event independently attributable.

Solid paths are verification calls or explicit imports. The relay path distributes signed discovery events; it is not settlement.

The evidence path

  1. An order artifact is supplied.A direct import, a supported market adapter, or a signed OpenOrdex-compatible event introduces a PSBT plus context.
  2. The gateway normalizes it.Strict parsing derives deterministic inputs, digest, protocol metadata, and a safety classification.
  3. Configured services verify it.Core checks each required UTXO. ord checks any claimed inscription location. Each outcome is recorded as a lifecycle state.
  4. The projection becomes searchable.Markets and users filter a normalized inventory by protocol, token, state, source, safety, price, and side.
  5. A publisher distributes a signed event.A NIP-07 signer signs the prepared kind-802 envelope; selected relays acknowledge delivery; gateways independently verify it before indexing.

Market discovery without a central listing gate

A compatible market can operate a gateway for its users, ingest signed events from chosen relays, and expose the same protocol/token filters as any other market. A user can instead connect the client to their own gateway. This makes listings portable while preserving different market interfaces, moderation policies, and liquidity experiences.

Portability does not erase market choice.

Ordex lets markets share inspectable evidence. It does not require a market to display every event, remove its own safety policy, or route settlement through a third party.

Failure behavior is explicit

If a gateway cannot reach Core, the order is PENDING_NODE, not implicitly live. If the ordinal index is incomplete, the order is PENDING_ORD. If an input is unavailable, the order is MEMPOOL_CONFLICTED. These states make different gateway results explainable instead of hiding uncertainty behind a single green badge.
