Ordex MCP server

Ten read-only tools over the Ordex specifications, contracts, conformance vectors, refusal codes and reference verifiers. Run it locally over stdio, or call a docs service over Streamable HTTP.

No tool holds keys, signs, broadcasts or contacts a gateway. Verifier results are local reference checks, not chain state.

1. Build the stdio server

Needs Node.js 24.19.0 and git. The build writes one self-contained file, dist/mcp/ordex-mcp-stdio.mjs, that you can copy anywhere. The checkout pins the exact revision this page was built from.

Build commands
git clone https://github.com/bitcoinuniverseio/ordex
cd ordex
git checkout 1b66fc7cf9bea3d5fe5bdbe10242573c25562bbb
npm ci
npm run build
Setup check (macOS, Linux, Git Bash)
printf '%s\n' '{"jsonrpc":"2.0","id":1,"method":"server/discover","params":{"_meta":{"io.modelcontextprotocol/protocolVersion":"2026-07-28","io.modelcontextprotocol/clientCapabilities":{}}}}' | node '/path/to/ordex-mcp-stdio.mjs'
Setup check (PowerShell)
'{"jsonrpc":"2.0","id":1,"method":"server/discover","params":{"_meta":{"io.modelcontextprotocol/protocolVersion":"2026-07-28","io.modelcontextprotocol/clientCapabilities":{}}}}' | node '/path/to/ordex-mcp-stdio.mjs'

A working install prints one JSON line whose supportedVersions is ["2026-07-28"] and whose server version is the revision you built, then exits.

2. Add it to your client

  • Needs Claude Code 2.1.274 or later on its v2 MCP runtime, which adds revision 2026-07-28.
  • For this stdio server, start Claude Code with the environment variable MCP_PROTOCOL_NEGOTIATION=auto. Without it Claude Code opens stdio servers with the older initialize handshake, which this server refuses.
  • Over HTTP, the v2 runtime asks the server for the newer revision by default.
Command
claude mcp add --transport stdio ordex -- node '/path/to/ordex-mcp-stdio.mjs'
Config: .mcp.json (project scope), or use the command above
{
  "mcpServers": {
    "ordex": {
      "type": "stdio",
      "command": "node",
      "args": [
        "/path/to/ordex-mcp-stdio.mjs"
      ]
    }
  }
}
Confirm the connection
claude mcp get ordex
Client documentation (opens in a new tab)

3. Check an HTTP endpoint

This build has no hosted endpoint configured. Enter one, for example a docs service you run with node dist/server/node-host.mjs (http://127.0.0.1:8787/mcp). The check sends real requests from this browser; the service must allow this page's origin.

This call as an HTTP request

Every request carries its protocol version and client capabilities in params._meta, mirrored in the MCP-Protocol-Version, Mcp-Method and Mcp-Name headers. There is no initialize handshake and no session.

HTTP request
POST /mcp HTTP/1.1
Host: 127.0.0.1:8787
Content-Type: application/json
Accept: application/json, text/event-stream
MCP-Protocol-Version: 2026-07-28
Mcp-Method: tools/call
Mcp-Name: ordex.search_docs

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "ordex.search_docs",
    "arguments": {
      "query": "public ask seller payment",
      "limit": 5
    },
    "_meta": {
